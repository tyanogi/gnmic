# Product Guide

## Project Overview
`gnmic` は、gNMI (gRPC Network Management Interface) を利用してネットワークデバイスの管理・運用を効率化するための高度なCLIクライアントおよびコレクターです。ネットワークエンジニアやインフラ自動化エンジニアが、複雑なネットワーク環境において迅速なデバッグ、テスト、および統一された設定管理を行えるようにすることを目指しています。

## Target Users
- **ネットワークエンジニア・運用者**: デバイスの状態確認や設定変更をgNMIを通じて直感的に行いたいユーザー。
- **インフラ自動化エンジニア**: ネットワーク構成の自動化パイプラインにgNMIを組み込み、効率的なプロビジョニングを実現したいユーザー。

## Core Goals
- **デバッグとテストの効率化**: gNMI対応デバイスとのやり取りを容易にし、迅速な問題解決を可能にする。
- **統一された設定管理**: ベンダーや機種に依存せず、gNMI標準に基づいた統一的な操作感で設定変更を管理する。

## Key Features
- **利便性の向上**:
    - CLIの対話型モード（Prompt）において、ターゲットからリソース値を自動取得する非同期プリフェッチ機能を備えた強力な自動補完を提供。
    - 設定ファイルやパスの自動生成機能を改善し、複雑な設定作業を簡略化。
- **堅牢なgNMIサポート**: Get, Set, Subscribe, Capabilitiesといった主要なRPCを完全にサポート。

## Success Metrics (KPIs)
- **導入の容易さとドキュメント**: ユーザーが迅速にツールを使いこなせるよう、設定の簡便さと情報の充実度を追求する。
- **広範な相互運用性**: 多様なネットワークOS (NOS) との互換性を確保し、あらゆる環境で安定して動作することを確認する。
